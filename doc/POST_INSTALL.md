The default username is `admin` and the password is the one you set during installation.

If your ynh server is behind a firewall, you must open these ports for any of the services you wish to use: 
- `SSH: __PORT_SSH__`
- `MySQL: __PORT_MYSQL__`
- `Postgresql: __PORT_POSTGRES__`
- `Kubernetes: __PORT_KUBERNETES__`
- `VNC: __PORT_VNC__`
- `RDP: __PORT_RDP__`
